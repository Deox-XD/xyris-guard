Command Center

Clean, Powerful Commands

Search or filter through commands with instant copy.

!antinuke enable / disable
Toggles the full anti-nuke suite with instant threat response.
!whitelist add <@user>
Whitelists a trusted admin from triggering anti-nuke sanctions.
!extraowner <add/remove> <@user>
Grants trusted co-owners permission to modify security settings.
!antiraid <on/off>
Enables automatic server protection against mass join raids.
!automod setup
Launches interactive setup for link filters, bad words, and spam rules.
!amwhitelist <@user/@role>
Bypasses automod filters for moderators or trusted roles.
!amfilter <type> <action>
Sets punitive action (delete, warn, mute) for specific infractions.
!lockall / !unlockall
Instantly freezes or unfreezes every public channel in the server.
!purgebots <amount>
Deletes messages sent only by automated bots within recent history.
!mute <@user> <duration> [reason]
Times out an offender with automated DM notifications.
!help
Opens the interactive categorized menu of all available bot commands.
!serverinfo / !userinfo
Displays rich analytical embeds with account ages, roles, and safety tags.
!ticket setup
Creates a reactive ticket panel with buttons for user inquiries.
